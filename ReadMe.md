## サイトについて

VRChatで撮影した写真と、その作品についての考えや撮影意図を掲載しています。
活動報告では、これまで制作したWebサイトの制作過程や工夫、課題を紹介しています。
今後は3Dゲームなどの制作進捗も追加していくことを想定しています。
一部の作品詳細ページは準備中です。

## 使用技術・主な構成

- HTML / CSS：ページ構造、Grid・Flexによるレイアウト、額縁・照明などの表現
- JavaScript：メニュー開閉、画像モーダル、スクロールに応じた点灯
- PHP：共通パーツの読み込み、配列による一覧表示、ページ分割、セッションによる閲覧日時の保持
- XAMPP：ローカル開発・動作確認環境

このサイト自体の一覧データはPHPの配列で管理しており、データベースは使用していません。
活動報告で紹介する別作品の使用技術とは異なります。

- `images/`：画像素材

## ローカルでの確認方法

1. PHPを実行できる環境を用意します。制作時はXAMPPを使用しています。
2. XAMPPの `htdocs` 内に `liolion.shop` フォルダーとして配置します。
3. Apacheを起動し、ブラウザーで `http://localhost/liolion.shop/` を開きます。

PHPファイルを直接開くのではなく、Webサーバー経由で確認してください。
ローカルの設置フォルダー名を変更する場合は、`app/config.php` の `$basePath` も変更してください。
現在の設定では、公開環境はドメイン直下への配置を想定しています。
